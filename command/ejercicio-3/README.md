
Este proyecto demuestra cómo implementar el patrón de diseño **Comando (Command)** en un entorno Fullstack profesional:
- **Backend**: API REST en Java puro (utilizando el servidor HTTP nativo del JDK, con soporte CORS).
- **Frontend**: Aplicación interactiva creada en React.js.

---

## Pasos para Ejecutar el Proyecto

### 1. Iniciar el Backend en Java
1. Abre la carpeta `servidor-java` en tu IDE preferido (IntelliJ IDEA o Eclipse).
2. Ejecuta la clase `com.ejemplo.comando.servidor.ServidorWeb`.
3. Verás la confirmación en consola:
   `🚀 Backend Java API iniciado en: http://localhost:8080`

### 2. Iniciar el Frontend en React
1. Abre la terminal dentro de la carpeta `cliente-react`.
2. Instala las dependencias ejecutando:
   ```bash
   npm install
   ```
3. Inicia el servidor de desarrollo de Vite:
   ```bash
   npm run dev
   ```
4. Abre la dirección generada en tu navegador (por ejemplo `http://localhost:5173`).
